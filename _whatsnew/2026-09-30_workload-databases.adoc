=== 単一インスタンスで複数のファイルシステムをサポート

Workload Factory for Databases は、単一の Microsoft SQL Server インスタンスに対して複数のファイルシステムをサポートします。SQL Server インスタンスに複数のファイルシステムを登録し、SQL Server インスタンス内の複数のファイルシステムに関する構成上の問題を同時に修正できます。
