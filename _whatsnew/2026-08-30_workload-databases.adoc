=== 貯蓄計算ツールのアップデート

FSx for ONTAP ファイルシステム上のデータベースワークロードにおける Microsoft SQL Server ワークロードの実行コストのさまざまな要素（ストレージ、コンピューティング、SQL ライセンス、スナップショット、クローンなど）を、Elastic Block Store （EBS）、FSx for Windows File Server、およびオンプレミスストレージと比較できます。この比較には、表示、計画、分析の権限のみを使用します。
